# UX010: Unconditional chat output on login

**Category:** ux

## Why

Every "MyAddon v1.2 loaded!" line pushes the player's chat up; with a dozen addons the login chat is a wall of banners. Print on first run or after an update, or behind an opt-in option. Warnings about real problems and debug output are not reported. One line is `info`; several are `warn`.

## Bad

```lua
print("Fixture loaded. Type /fixture for options.")

local frame = CreateFrame("Frame")
frame:RegisterEvent("PLAYER_LOGIN")
frame:SetScript("OnEvent", function(self, event)
    if event == "PLAYER_LOGIN" then
        print("Fixture ready.")
    end
end)
```

## Good

```lua
local frame = CreateFrame("Frame")
frame:RegisterEvent("PLAYER_LOGIN")
frame:SetScript("OnEvent", function(self, event)
    if event == "PLAYER_LOGIN" then
        FixtureDB = FixtureDB or {}
        if not FixtureDB.welcomeSeen then
            print("Fixture: type /fixture for options.")
            FixtureDB.welcomeSeen = true
        end
    end
end)
```
