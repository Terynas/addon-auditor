# TOC004: TOC / XML lists a file that does not exist

**Category:** toc

## Why

A missing file is skipped with a 'file not found' log line. Everything it would have defined is nil, so the first file that uses it throws. Typical after renaming or moving a file. Paths under a `.pkgmeta` `externals:` entry are not reported (the packager fetches them). Paths that climb into a sibling addon (`..\BagBrother\core.xml`) are resolved on disk and, if absent, reported as a low-confidence warning.

## Bad

```ini
core.lua
Modules\Missing.lua   <- not on disk
```

## Good

```ini
Libs\LibStub\LibStub.lua   <- fetched via .pkgmeta externals
core.lua
```
