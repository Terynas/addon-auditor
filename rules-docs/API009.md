# API009: GetItemInfo result used without a nil check

**Category:** api

## Why

Item data is streamed from the server. `GetItemInfo` / `C_Item.GetItemInfo` return nil for an item the client has not cached yet, so `name:upper()`, `"[" .. name .. "]"` or `ilvl > 100` throw the first time a new item is seen (and work on the next /reload, which hides the bug). Check for nil and retry when `GET_ITEM_INFO_RECEIVED` fires, or use `Item:ContinueOnItemLoad`.

## Bad

```lua
local function Label(itemID)
  local name, _, quality = C_Item.GetItemInfo(itemID)
  return "[" .. name .. "] q" .. quality
end
print(Label(6948))
```

## Good

```lua
local function Label(itemID)
  local name, _, quality = C_Item.GetItemInfo(itemID)
  if not name then
    C_Item.RequestLoadItemDataByID(itemID)
    return nil
  end
  return "[" .. name .. "] q" .. quality
end
print(Label(6948))
```
