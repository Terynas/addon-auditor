# RUN005: Frame hitch

**Category:** runtime

## Why

A single slow frame (one long loop, a full rebuild) is felt as a stutter even if the average CPU is low. 16.7 ms is the whole budget of a 60 FPS frame.

## Bad

```lua
for i = 1, 20000 do ScanItem(i) end
```

## Good

```lua
local co = coroutine.create(function()
  for i = 1, 20000 do
    ScanItem(i)
    if i % 500 == 0 then coroutine.yield() end
  end
end)
local function step() if coroutine.resume(co) and coroutine.status(co) ~= "dead" then C_Timer.After(0, step) end end
step()
```
