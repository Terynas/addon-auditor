# SV002: ADDON_LOADED handler does not check the addon name

**Category:** savedvars

## Why

`ADDON_LOADED` fires once per addon (including Blizzard load-on-demand modules), with the addon name as its first argument. Initialising SavedVariables without comparing that name runs the init for the first addon that loads (before this addon's SVs exist, so defaults overwrite nothing and get replaced) and again for every later addon, re-merging or resetting data. Compare against `local addonName = ...` (or the literal folder name) and unregister afterwards.

## Bad

```lua
local f = CreateFrame("Frame")
f:RegisterEvent("ADDON_LOADED")
f:SetScript("OnEvent", function(self, event)
  MyAddonDB = MyAddonDB or {}
  MyAddonDB.loads = (MyAddonDB.loads or 0) + 1
end)
```

## Good

```lua
local addonName = ...
local f = CreateFrame("Frame")
f:RegisterEvent("ADDON_LOADED")
f:SetScript("OnEvent", function(self, event, loaded)
  if loaded ~= addonName then return end
  MyAddonDB = MyAddonDB or {}
  MyAddonDB.loads = (MyAddonDB.loads or 0) + 1
  self:UnregisterEvent("ADDON_LOADED")
end)
```
