# SEC004: Combat-locked operation without InCombatLockdown() check

**Category:** security

## Why

Frames built from `SecureActionButtonTemplate` / `Secure*Template` / `SecureHandler*` cannot be shown, hidden, moved, resized, re-parented or have attributes set while in combat, and `RegisterStateDriver`, `SetBinding*`, `SetOverrideBinding*` and `ClearOverrideBindings` are locked too. Event handlers such as `GROUP_ROSTER_UPDATE` fire mid-combat, so the call is blocked and the addon is blamed. Handlers for login and `PLAYER_REGEN_*` events, and calls behind an `InCombatLockdown()` check, are not reported. Defer with `PLAYER_REGEN_ENABLED`.

## Bad

```lua
local btn = CreateFrame("Button", "MyAddonTargetButton", UIParent, "SecureActionButtonTemplate")
btn:SetAttribute("type", "target")
local f = CreateFrame("Frame")
f:RegisterEvent("GROUP_ROSTER_UPDATE")
f:SetScript("OnEvent", function()
  btn:SetAttribute("unit", "party1")
  btn:Show()
end)
```

## Good

```lua
local btn = CreateFrame("Button", "MyAddonTargetButton", UIParent, "SecureActionButtonTemplate")
btn:SetAttribute("type", "target")
local pending = false
local f = CreateFrame("Frame")
f:RegisterEvent("GROUP_ROSTER_UPDATE")
f:RegisterEvent("PLAYER_REGEN_ENABLED")
f:SetScript("OnEvent", function(self, event)
  if InCombatLockdown() then
    pending = true
    return
  end
  if event == "PLAYER_REGEN_ENABLED" and not pending then return end
  pending = false
  btn:SetAttribute("unit", "party1")
  btn:Show()
end)
```
