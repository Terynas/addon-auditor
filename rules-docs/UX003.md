# UX003: Window does not close with Escape

**Category:** ux

## Why

Every Blizzard window closes with Esc, so players expect addon windows to do the same. A window that ignores Esc forces a hunt for its close button (and Esc opens the game menu instead). Add the window's global name to `UISpecialFrames`; unnamed frames cannot be registered, so give windows a name.

## Bad

```lua
local f = CreateFrame("Frame", "FixtureWindow", UIParent, "BasicFrameTemplateWithInset")
f:SetSize(320, 240)
f:SetPoint("CENTER")
f:Hide()
```

## Good

```lua
local f = CreateFrame("Frame", "FixtureWindow", UIParent, "BasicFrameTemplateWithInset")
f:SetSize(320, 240)
f:SetPoint("CENTER")
f:Hide()
tinsert(UISpecialFrames, "FixtureWindow")

SLASH_FIXTURE1 = "/fixture"
SlashCmdList.FIXTURE = function()
    f:SetShown(not f:IsShown())
end
```
