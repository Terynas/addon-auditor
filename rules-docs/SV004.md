# SV004: Function or frame stored in SavedVariables

**Category:** savedvars

## Why

SavedVariables serialize only nil, booleans, numbers, strings and tables of those. Functions, frames, textures and other userdata are dropped (or break the write), so whatever depended on them is gone next session. Store a frame's name or position, or a key that selects a function, and keep live objects in a non-saved table. Writes through aliases such as `ns.db = MyAddonDB` and `local db = MyAddonDB` are followed.

## Bad

```lua
local addonName = ...
local f = CreateFrame("Frame")
f:RegisterEvent("ADDON_LOADED")
f:SetScript("OnEvent", function(self, event, loaded)
  if loaded ~= addonName then return end
  MyAddonDB = MyAddonDB or {}
  MyAddonDB.anchor = CreateFrame("Frame", nil, UIParent)
  MyAddonDB.onClick = function() print("clicked") end
end)
```

## Good

```lua
local addonName = ...
local anchor = CreateFrame("Frame", "MyAddonAnchor", UIParent)
local f = CreateFrame("Frame")
f:RegisterEvent("ADDON_LOADED")
f:SetScript("OnEvent", function(self, event, loaded)
  if loaded ~= addonName then return end
  MyAddonDB = MyAddonDB or {}
  MyAddonDB.anchorName = anchor:GetName()
  MyAddonDB.clickAction = "print"
end)
```
