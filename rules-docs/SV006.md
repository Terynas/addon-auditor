# SV006: SavedVariables table replaced after load

**Category:** savedvars

## Why

`MyAddonDB = {}` (or a fresh copy of the defaults) inside a runtime function throws away everything the player saved. It is usually a misplaced initialisation that should have been `MyAddonDB = MyAddonDB or {}` plus per-key defaults. Replacements guarded by a check on the SV itself, inside load/init event handlers, or in an explicit reset path (a `reset` slash argument, a function named `Reset...`, a StaticPopup `OnAccept`) are not reported.

## Bad

```lua
local function RecordLoot(itemLink)
  MyAddonDB = { loot = {} }
  table.insert(MyAddonDB.loot, itemLink)
end
local f = CreateFrame("Frame")
f:RegisterEvent("CHAT_MSG_LOOT")
f:SetScript("OnEvent", function(self, event, text)
  RecordLoot(text)
end)
```

## Good

```lua
local function RecordLoot(itemLink)
  MyAddonDB = MyAddonDB or {}
  MyAddonDB.loot = MyAddonDB.loot or {}
  table.insert(MyAddonDB.loot, itemLink)
end
SLASH_MYADDON1 = "/myaddon"
SlashCmdList.MYADDON = function(msg)
  if msg == "reset" then MyAddonDB = {} end
end
local f = CreateFrame("Frame")
f:RegisterEvent("CHAT_MSG_LOOT")
f:SetScript("OnEvent", function(self, event, text)
  RecordLoot(text)
end)
```
