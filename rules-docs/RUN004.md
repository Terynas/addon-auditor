# RUN004: High CPU usage

**Category:** runtime

## Why

Addon code runs on the render thread. Every millisecond per second an addon spends is taken from frame time; above about 1 ms/s it becomes visible in the AddOn profiler and in raids.

## Bad

```lua
frame:SetScript("OnUpdate", function(self, elapsed)
  RefreshEverything()
end)
```

## Good

```lua
frame:SetScript("OnUpdate", function(self, elapsed)
  self.t = (self.t or 0) + elapsed
  if self.t < 0.2 then return end
  self.t = 0
  RefreshVisible()
end)
```
