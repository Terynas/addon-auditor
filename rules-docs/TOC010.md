# TOC010: TOC line longer than 1024 characters

**Category:** toc

## Why

The client reads only the first 1024 characters of each TOC line. A long `## Notes`, a long `## SavedVariables` list or a deep file path is cut off without any error.

## Bad

```ini
## Notes: <1100 characters of text>
```

## Good

```ini
## Notes: One short sentence about the addon.
```
