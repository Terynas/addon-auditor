# API005: Protected call that addons cannot make on Forever

**Category:** api

## Why

`TargetUnit`, `TargetByName`, `TargetLastTarget`, `ClearTarget` and the `TargetNearest*` family are protected. On Forever calling them from addon code shows an 'Interface action failed' popup and `pcall` does not hide it. `ChatFrame_OpenChat` / `ChatEdit_ActivateChat` fail silently (reported as a warning). Let the player act through a secure button or macro instead.

## Bad

```lua
local function Focus(name)
  TargetUnit(name)
end
Focus("Hogger")
```

## Good

```lua
local btn = CreateFrame("Button", "FixtureTargetButton", UIParent,
  "SecureActionButtonTemplate")
btn:SetAttribute("type", "macro")
btn:SetAttribute("macrotext", "/target Hogger")
```
