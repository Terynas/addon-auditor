# TOC008: Database-like global is not declared in SavedVariables

**Category:** toc

## Why

`MyAddonDB = MyAddonDB or {}` (or `if not MyAddonDB then MyAddonDB = {} end`) is the SavedVariables initialisation idiom. If the name is not declared in the TOC, the table is rebuilt from scratch on every login and the user's settings never persist. Only names that look like a database (`...DB`, `...Settings`, `...SavedVars`, `...Prefs`) initialised with that idiom are reported.

## Bad

```lua
-- no ## SavedVariables line
FixtureDB = FixtureDB or { scale = 1 }
```

## Good

```lua
## SavedVariables: FixtureDB

-- core.lua
FixtureDB = FixtureDB or { scale = 1 }
```
