# TOC005: File path case differs from the file on disk

**Category:** toc

## Why

Windows resolves `Core.lua` to `core.lua`, but Linux (Wine/Proton players), case-sensitive macOS volumes and some packaging tools do not. The file then fails to load only for some users, which is very hard to debug from a bug report.

## Bad

```ini
Core.lua      <- file on disk is core.lua
```

## Good

```ini
core.lua
```
