# SEC009: Call to a protected function from addon code

**Category:** security

## Why

Casting (`CastSpellByName`), using actions (`UseAction`), targeting (`TargetUnit`, `ClearTarget`) and running macros (`RunMacroText`) are protected: only Blizzard's secure code may call them, for example when the player clicks a `SecureActionButtonTemplate` button. From addon Lua they are always blocked (`ADDON_ACTION_FORBIDDEN`), in or out of combat, typically after an AI assistant "just calls the API".

## Bad

```lua
local btn = CreateFrame("Button", "MyAddonCastButton", UIParent, "UIPanelButtonTemplate")
btn:SetScript("OnClick", function()
  CastSpellByName("Frostbolt")
end)
```

## Good

```lua
local btn = CreateFrame("Button", "MyAddonCastButton", UIParent, "SecureActionButtonTemplate")
btn:RegisterForClicks("AnyDown")
btn:SetAttribute("type", "spell")
btn:SetAttribute("spell", "Frostbolt")
```
