# API008: Chat language taken from GetDefaultLanguage

**Category:** api

## Why

`GetDefaultLanguage()` returns the language *name* (`"Common"`) and then its numeric ID. The send API's third argument is a languageID; on Forever passing the name throws `outside of expected range 0 to 4294967295`. As the last argument it also spills the ID into the `target` slot. Pass `nil` to speak the character's default language.

## Bad

```lua
local function Say(text)
  local lang = GetDefaultLanguage("player")
  C_ChatInfo.SendChatMessage(text, "SAY", lang)
end
Say("hello")
```

## Good

```lua
local function Say(text)
  C_ChatInfo.SendChatMessage(text, "SAY", nil)
end
Say("hello")
```
