# TOC011: Missing recommended TOC metadata

**Category:** toc

## Why

`## Title` is the name in the AddOns list, `## Notes` its tooltip, and `## Version` what users quote in bug reports (use `@project-version@` to let the packager stamp the git tag). Each per-client TOC is read on its own, so each needs them. Localised variants (`Title-deDE`) count.

## Bad

```ini
## Interface: 16001, 120107
## Title: Fixture
```

## Good

```ini
## Interface: 16001, 120107
## Title: Fixture
## Notes: What it does.
## Version: @project-version@
```
