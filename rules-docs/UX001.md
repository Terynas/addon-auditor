# UX001: Windowed addon without a slash command

**Category:** ux

## Why

Players open addon windows from chat (`/myaddon`) or bind them in macros. A window with no slash command can only be reached through whatever button the addon happens to provide, and is lost entirely if that button is hidden.

## Bad

```lua
local f = CreateFrame("Frame", "FixtureWindow", UIParent, "BasicFrameTemplateWithInset")
f:SetSize(320, 240)
f:SetPoint("CENTER")
f:Hide()
```

## Good

```lua
local f = CreateFrame("Frame", "FixtureWindow", UIParent, "BasicFrameTemplateWithInset")
f:SetSize(320, 240)
f:SetPoint("CENTER")
f:Hide()
tinsert(UISpecialFrames, "FixtureWindow")

SLASH_FIXTURE1 = "/fixture"
SlashCmdList.FIXTURE = function(msg)
    f:SetShown(not f:IsShown())
end
```
