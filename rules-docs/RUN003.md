# RUN003: Memory keeps growing

**Category:** runtime

## Why

A steady upward slope means garbage is produced faster than it is reused, or a cache never evicts. The Lua GC then runs more often and longer, which shows up as frame-time spikes.

## Bad

```lua
frame:SetScript("OnUpdate", function()
  local pos = { GetPlayerMapPosition("player") }
end)
```

## Good

```lua
local pos = {}
frame:SetScript("OnUpdate", function()
  pos[1], pos[2] = GetPlayerMapPosition("player")
end)
```
