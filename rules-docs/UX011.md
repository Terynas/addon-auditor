# UX011: Popup or window opened on every login

**Category:** ux

## Why

A StaticPopup or addon window that opens on every login blocks the player before they can move and trains them to dismiss it unread. Show intros once (store a seen-flag) and what's-new notes only when the stored version changes.

## Bad

```lua
StaticPopupDialogs.FIXTURE_WELCOME = { text = "Welcome to Fixture!", button1 = OKAY }

local frame = CreateFrame("Frame")
frame:RegisterEvent("PLAYER_LOGIN")
frame:SetScript("OnEvent", function(self, event)
    if event == "PLAYER_LOGIN" then
        StaticPopup_Show("FIXTURE_WELCOME")
    end
end)
```

## Good

```lua
StaticPopupDialogs.FIXTURE_WELCOME = { text = "Welcome to Fixture!", button1 = OKAY }

local frame = CreateFrame("Frame")
frame:RegisterEvent("PLAYER_LOGIN")
frame:SetScript("OnEvent", function(self, event)
    if event == "PLAYER_LOGIN" then
        FixtureDB = FixtureDB or {}
        if not FixtureDB.introSeen then
            StaticPopup_Show("FIXTURE_WELCOME")
            FixtureDB.introSeen = true
        end
    end
end)
```
