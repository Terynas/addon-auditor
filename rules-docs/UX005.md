# UX005: Movable frame position is not saved

**Category:** ux

## Why

If a player moves a frame and it snaps back to the default spot on every reload, moving it was pointless. Store the anchor from `GetPoint()` in SavedVariables when dragging stops and restore it on load. Named frames moved with `StartMoving` are kept by the client layout cache, so the rule only reports anonymous frames (or ones with `SetDontSavePosition(true)`).

## Bad

```lua
local f = CreateFrame("Frame", nil, UIParent)
f:SetSize(200, 100)
f:SetPoint("CENTER")
f:SetMovable(true)
f:SetClampedToScreen(true)
f:EnableMouse(true)
f:RegisterForDrag("LeftButton")
f:SetScript("OnDragStart", f.StartMoving)
f:SetScript("OnDragStop", f.StopMovingOrSizing)
```

## Good

```lua
FixtureDB = FixtureDB or {}

local f = CreateFrame("Frame", nil, UIParent)
f:SetSize(200, 100)
f:SetPoint("CENTER")
f:SetMovable(true)
f:SetClampedToScreen(true)
f:EnableMouse(true)
f:RegisterForDrag("LeftButton")
f:SetScript("OnDragStart", f.StartMoving)
f:SetScript("OnDragStop", function(self)
    self:StopMovingOrSizing()
    local point, _, relativePoint, x, y = self:GetPoint()
    FixtureDB.position = { point = point, relativePoint = relativePoint, x = x, y = y }
end)
```
