# UX008: Settings stored but no options panel

**Category:** ux

## Why

Players look for addon settings under Options -> AddOns. If the addon keeps settings in SavedVariables but registers no panel there, they can only be changed through slash commands the player has to discover. This is a low-confidence hint: small addons can be fine with slash-only settings.

## Bad

```lua
local defaults = { scale = 1, locked = false }

FixtureDB = FixtureDB or CopyTable(defaults)
```

## Good

```lua
local defaults = { scale = 1, locked = false }

FixtureDB = FixtureDB or CopyTable(defaults)

if Settings and Settings.RegisterVerticalLayoutCategory then
    local category = Settings.RegisterVerticalLayoutCategory("Fixture")
    Settings.RegisterAddOnCategory(category)
end
```
