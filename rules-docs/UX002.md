# UX002: Slash command ignores its arguments or has no help

**Category:** ux

## Why

A slash handler that silently ignores unknown input leaves the player guessing. Always handle an empty `msg` and `help`, and answer anything unrecognised with the list of sub-commands. When the addon has a window, options and a minimap button, a handler that ignores `msg` hides most of them from chat.

## Bad

```lua
FixtureDB = FixtureDB or {}

SLASH_FIXTURE1 = "/fixture"
SlashCmdList.FIXTURE = function(msg)
    if msg == "reset" then
        FixtureDB = {}
    end
end
```

## Good

```lua
FixtureDB = FixtureDB or {}

SLASH_FIXTURE1 = "/fixture"
SlashCmdList.FIXTURE = function(msg)
    local cmd = (msg or ""):lower():match("^%s*(%S*)")
    if cmd == "reset" then
        FixtureDB = {}
        print("Fixture: reset.")
    else
        print("/fixture reset - clear saved data")
        print("/fixture help - this list")
    end
end
```
