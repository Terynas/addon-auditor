# TOC002: Missing or invalid ## Interface

**Category:** toc

## Why

`## Interface` tells each client whether the addon is up to date. It must be one or more comma-separated integers (`12.1.7` is written `120107`, Forever 1.60.1 is `16001`). A missing or malformed value makes the addon 'out of date' everywhere. `## Interface: 0` is accepted: it is the idiom for a fallback TOC that only shows an 'unsupported client' message.

## Bad

```ini
## Interface: 1.15.7
## Title: Fixture
```

## Good

```ini
## Interface: 11508, 16001, 120107
## Title: Fixture
```
