# SEC006: Unthrottled automatic chat message

**Category:** security

## Why

`SendChatMessage` inside an event handler or OnUpdate sends once per trigger. Auto-replies to whispers, loot or roster announcements without a rate limit flood channels, get the player reported or muted, and can disconnect them for spamming; two such addons can even ping-pong. On Mainline, SAY/YELL/CHANNEL sends outside instances also need a hardware event. Handlers whose function compares against `GetTime()`/`time()` (or uses an obvious throttle variable) are not reported.

## Bad

```lua
local f = CreateFrame("Frame")
f:RegisterEvent("CHAT_MSG_WHISPER")
f:SetScript("OnEvent", function(self, event, text, sender)
  SendChatMessage("I am AFK", "WHISPER", nil, sender)
end)
```

## Good

```lua
local lastReply = {}
local f = CreateFrame("Frame")
f:RegisterEvent("CHAT_MSG_WHISPER")
f:SetScript("OnEvent", function(self, event, text, sender)
  local now = GetTime()
  if lastReply[sender] and now - lastReply[sender] < 60 then return end
  lastReply[sender] = now
  SendChatMessage("I am AFK", "WHISPER", nil, sender)
end)
```
