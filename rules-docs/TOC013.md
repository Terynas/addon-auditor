# TOC013: Addon depends on itself

**Category:** toc

## Why

An addon listed in its own `## Dependencies`, `## OptionalDeps` or `## LoadWith` forms a dependency loop, and the client refuses to load it.

## Bad

```ini
# MyAddon/MyAddon.toc
## Dependencies: Ace3, MyAddon
```

## Good

```ini
# MyAddon/MyAddon.toc
## OptionalDeps: Ace3
```
