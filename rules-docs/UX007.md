# UX007: Minimap button cannot be hidden

**Category:** ux

## Why

The minimap ring fills up quickly. Players expect every minimap button to have a "Show minimap icon" option (or `/cmd minimap`); without one the only way to remove it is to disable the addon. LibDBIcon honours a `hide` key in the table you register, so store one in SavedVariables.

## Bad

```lua
FixtureDB = FixtureDB or {}

local btn = CreateFrame("Button", "FixtureMinimapButton", Minimap)
btn:SetSize(32, 32)
btn:SetPoint("CENTER", Minimap, "CENTER", -70, 0)
btn:SetNormalTexture("Interface\\Icons\\INV_Misc_QuestionMark")
```

## Good

```lua
FixtureDB = FixtureDB or { minimap = { hide = false } }

local btn = CreateFrame("Button", "FixtureMinimapButton", Minimap)
btn:SetSize(32, 32)
btn:SetPoint("CENTER", Minimap, "CENTER", -70, 0)
btn:SetNormalTexture("Interface\\Icons\\INV_Misc_QuestionMark")
btn:SetShown(not FixtureDB.minimap.hide)
```
