# SEC005: Generic or colliding global name

**Category:** security

## Why

All addons share one global table. A global called `db`, `L`, `frame` or `Config`, or a frame named `MainFrame`, is overwritten by the next addon that picks the same name (or overwrites theirs); a frame named like a Blizzard one (`PlayerFrame`, `GameTooltip`) replaces the default UI's object and is an `error`. SavedVariables, `SLASH_*`, `BINDING_*` and additions to `SlashCmdList` / `StaticPopupDialogs` / `UISpecialFrames` are exempt. Names prefixed with the addon's name, TOC title, their initials, or the addon's own namespace table are fine. Other unprefixed Lua globals are reported by LINT003 instead.

## Bad

```lua
db = {}
local main = CreateFrame("Frame", "MainFrame", UIParent)
main:Hide()
print(db)
```

## Good

```lua
local _, ns = ...
ns.db = {}
local main = CreateFrame("Frame", "MyAddonMainFrame", UIParent)
main:Hide()
print(ns.db)
```
