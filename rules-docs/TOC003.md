# TOC003: Per-client TOC suffix does not match its Interface

**Category:** toc

## Why

The client picks `_Vanilla.toc` on Classic Era, `_Mists.toc` on Mists Classic, `_Mainline.toc` on the Mainline family (Midnight and Forever), and so on. A suffixed TOC whose Interface numbers all belong to a different client is a copy-paste slip: the addon shows as out of date on the client that actually reads it.

## Bad

```ini
# MyAddon_Vanilla.toc
## Interface: 120107
```

## Good

```ini
# MyAddon_Vanilla.toc
## Interface: 11508
```
