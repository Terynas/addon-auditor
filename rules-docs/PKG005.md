# PKG005: Vendored library without a version marker

**Category:** packaging

## Why

LibStub libraries carry a MINOR version so the newest embedded copy wins. A library folder with no `NewLibrary(MAJOR, MINOR)`, no `## Version` and no `.pkgmeta` external cannot be updated safely and may clobber other addons' copies. Low confidence: some small helpers are fine as-is.

## Bad

```lua
-- Libs/LibFoo/LibFoo.lua
LibFoo = {}
```

## Good

```lua
-- Libs/LibFoo/LibFoo.lua
local MAJOR, MINOR = "LibFoo-1.0", 3
local lib = LibStub:NewLibrary(MAJOR, MINOR)
if not lib then return end
```
