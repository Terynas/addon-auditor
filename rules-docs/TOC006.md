# TOC006: Lua file is never loaded

**Category:** toc

## Why

WoW only runs files listed in a TOC or included from a loaded XML file. A new module that was never added to the TOC 'does nothing' with no error. Libraries, tests and paths excluded in `.addon-auditor.toml`, `.pkgmeta` ignores, nested addons with their own TOC, files matched by TOC variables (`[Family]\File.lua`), files in commented-out TOC lines (`#Old.lua`, including scripts of a commented-out XML), LuaLS `---@meta` stubs, and addons whose files a sibling addon loads via `..\ThisAddon\` paths are not reported.

## Bad

```ini
# MyAddon.toc lists only core.lua
# Extra.lua exists on disk but never runs
```

## Good

```ini
core.lua
Extra.lua
```
