# API007: UnitName's second return treated as a realm on Forever

**Category:** api

## Why

On Forever `UnitName` and `UnitNameUnmodified` return `(firstName, surname)`. Code written for Mainline that stores the second value as `realm` or joins `name .. "-" .. realm` produces wrong whisper targets, mail recipients and dedupe keys. Use `UnitGUID` for identity, `GetNormalizedRealmName()` for the realm, and `first .. " " .. surname` for display.

## Bad

```lua
local function FullName(unit)
  local name, realm = UnitName(unit)
  return name .. "-" .. (realm or GetNormalizedRealmName())
end
print(FullName("target"))
```

## Good

```lua
local function DisplayName(unit)
  local first, surname = UnitName(unit)
  if surname and surname ~= "" then
    return first .. " " .. surname
  end
  return first
end
print(DisplayName("target"), UnitGUID("target"))
```
