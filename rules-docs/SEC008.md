# SEC008: Possibly secret value stored in SavedVariables

**Category:** security

## Why

On Midnight (12.x) and Forever, combat-sensitive values such as another unit's health, power, level or aura data can be *secret values*. They do not serialize (they save as nil) and any comparison or arithmetic on them taints the addon for the session. The notes list `UnitHealth`, `UnitLevel`, `UnitReaction` and `UnitAura`-style results as the main sources; values for the `"player"` unit are not reported. Scrub with `tonumber`/`scrubsecretvalues` or skip when `issecretvalue(v)`. Low confidence: exact secret rules vary by patch, verify in-game.

## Bad

```lua
local f = CreateFrame("Frame")
f:RegisterEvent("PLAYER_TARGET_CHANGED")
f:SetScript("OnEvent", function()
  MyAddonDB = MyAddonDB or {}
  MyAddonDB.lastTargetHealth = UnitHealth("target")
end)
```

## Good

```lua
local f = CreateFrame("Frame")
f:RegisterEvent("PLAYER_TARGET_CHANGED")
f:SetScript("OnEvent", function()
  MyAddonDB = MyAddonDB or {}
  local hp = UnitHealth("target")
  if not issecretvalue(hp) then
    MyAddonDB.lastTargetHealth = hp
  end
end)
```
