# SEC007: CHAT_MSG_ADDON payload used without checking the prefix

**Category:** security

## Why

`CHAT_MSG_ADDON` fires for every prefix registered by any addon on this client, from any sender. A handler that splits and acts on the payload before comparing its own prefix processes other addons' traffic or crafted messages. Check the prefix first, then validate version and fields. Payloads passed to `loadstring`/`RunScript` are reported as errors by SEC001.

## Bad

```lua
local f = CreateFrame("Frame")
f:RegisterEvent("CHAT_MSG_ADDON")
f:SetScript("OnEvent", function(self, event, ...)
  local prefix, message, channel, sender = ...
  local cmd, value = strsplit(":", message)
  print(cmd, value, sender)
end)
```

## Good

```lua
local PREFIX = "MyAddon"
C_ChatInfo.RegisterAddonMessagePrefix(PREFIX)
local f = CreateFrame("Frame")
f:RegisterEvent("CHAT_MSG_ADDON")
f:SetScript("OnEvent", function(self, event, ...)
  local prefix, message, channel, sender = ...
  if prefix ~= PREFIX then return end
  local cmd, value = strsplit(":", message)
  print(cmd, value, sender)
end)
```
