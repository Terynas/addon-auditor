# UX013: User-facing text bypasses the locale table

**Category:** ux

## Why

Once an addon ships a locale table, every hard-coded English label or chat line shows up untranslated for German, French or Russian players next to translated text. Only literal sentences passed to `SetText`, `AddLine`, `SetFormattedText` or `print` are counted, and each file gets one aggregated finding.

## Bad

```lua
local L = FixtureLocale

local f = CreateFrame("Frame", nil, UIParent)
local title = f:CreateFontString(nil, "OVERLAY", "GameFontNormal")
title:SetText(L["Fixture"])
local hint = f:CreateFontString(nil, "OVERLAY", "GameFontHighlightSmall")
hint:SetText("Drag items here to add them to the list.")
```

## Good

```lua
local L = FixtureLocale

local f = CreateFrame("Frame", nil, UIParent)
local title = f:CreateFontString(nil, "OVERLAY", "GameFontNormal")
title:SetText(L["Fixture"])
local hint = f:CreateFontString(nil, "OVERLAY", "GameFontHighlightSmall")
hint:SetText(L["Drag items here to add them to the list."])
```
