# TOC009: Invalid AllowLoadGameType / ExcludeLoadGameType

**Category:** toc

## Why

Valid game types are `standard`, `mainline`, `forever`/`camelot`, `classic`, `vanilla`, `tbc`, `wrath`, `cata`, `mists`, `plunderstorm`, `wowhack`. The client ignores unknown values, and if *none* is recognised the restriction is dropped entirely -- `retail` silently means 'load everywhere'. A type that is both allowed and excluded (directly or via its family) never loads.

## Bad

```ini
## AllowLoadGameType: retail, forever
```

## Good

```ini
## AllowLoadGameType: forever, standard
## ExcludeLoadGameType: classic
```
