# RUN002: High memory footprint

**Category:** runtime

## Why

Memory is shared by every addon and the UI. Large resident data (full item databases, per-item tables, cached tooltips) slows garbage collection for everyone and shows up in the in-game AddOn memory list that players use to decide what to uninstall.

## Bad

```lua
-- probe: mem ends at 9000 KB (threshold runtime_memory_kb_warn = 5000)
MyAddonDB.cache[itemID] = { name = name, link = link, icon = icon, quality = q }
```

## Good

```lua
-- pack rarely used fields, build caches on demand
MyAddonDB.cache[itemID] = link
```
