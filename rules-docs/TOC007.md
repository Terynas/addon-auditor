# TOC007: Declared SavedVariable is never used

**Category:** toc

## Why

The client saves exactly the globals named in `## SavedVariables`. If the code uses a different spelling (`MyAddon_DB` vs `MyAddonDB`), the real data is never saved and the declared name stays nil. Not reported when the name may be built at runtime (`_G[name .. "DB"]`, `AceDB:New(addonName .. "DB")`), or when the addon shares code with sibling addons through `..\Other\` TOC/XML paths.

## Bad

```lua
## SavedVariables: FixtureDB

-- core.lua
Fixture_DB = Fixture_DB or {}
```

## Good

```lua
## SavedVariables: FixtureDB

-- core.lua
FixtureDB = FixtureDB or {}
```
