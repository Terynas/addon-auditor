# API003: API missing on some targeted clients

**Category:** api

## Why

The addon targets several clients (for example `## Interface: 16001, 120107` for Forever and Mainline) but calls an API that only one of them has. It works where it was tested and throws `attempt to call/index a nil value` on the other. Calls guarded by an existence check or by a client check (`WOW_PROJECT_ID`, `isRetail`, ...) are not reported, and files loaded only for one client (per-client TOC or `[AllowLoadGameType ...]`) are judged against that client only. Plain globals are only reported as missing on Mainline, because the Forever data omits undocumented C functions.

## Bad

```lua
local function Stage()
  return C_Scenario.GetInfo()
end
print(Stage())
```

## Good

```lua
local function Stage()
  if C_Scenario and C_Scenario.GetInfo then
    return C_Scenario.GetInfo()
  end
end
local function Stage2()
  if WOW_PROJECT_ID ~= WOW_PROJECT_MAINLINE then return end
  return C_Scenario.GetInfo()
end
print(Stage(), Stage2())
```
