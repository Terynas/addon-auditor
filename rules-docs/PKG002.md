# PKG002: Development or junk files would ship

**Category:** packaging

## Why

Without an `ignore:` entry, art sources (`.psd`, `.blend`), archives, `node_modules`, OS metadata (`.DS_Store`, `Thumbs.db`) and test suites end up in every user's AddOns folder. The packager always drops dot-files, so editor folders like `.vscode` are only reported for addons zipped by hand (no `.pkgmeta` and no git checkout). Test folders without any `.pkgmeta` are reported as info/low, since a custom deploy script may strip them.

## Bad

```yaml
package-as: MyAddon
# Art/logo.psd ships
```

## Good

```yaml
package-as: MyAddon
ignore:
  - "*.psd"
  - tests
```
