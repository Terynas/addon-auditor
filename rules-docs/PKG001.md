# PKG001: .pkgmeta is malformed or packages under the wrong name

**Category:** packaging

## Why

The BigWigs / CurseForge packager names the zip's top folder after `package-as`. If that differs from the TOC name, the installed folder and its TOC no longer match and WoW ignores the addon. YAML also forbids tab indentation; a tab makes the release build fail.

## Bad

```yaml
# MyAddon/.pkgmeta
package-as: MyAddOn
```

## Good

```yaml
# MyAddon/.pkgmeta
package-as: MyAddon

ignore:
  - docs
```
