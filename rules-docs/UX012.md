# UX012: SetBackdrop on a frame without BackdropTemplate

**Category:** ux

## Why

Since patch 9.0 `SetBackdrop` and friends come from `BackdropTemplateMixin`; Forever, Classic Era and Mainline all require the `BackdropTemplate` template. Without it the call throws `attempt to call method 'SetBackdrop' (a nil value)` and the rest of the file stops loading. The rule follows the frame from `CreateFrame` (including helpers it is passed to) and stays quiet when the template is a variable or the call is guarded with `if f.SetBackdrop then`.

## Bad

```lua
local f = CreateFrame("Frame", nil, UIParent)
f:SetSize(200, 100)
f:SetPoint("CENTER")
f:SetBackdrop({ bgFile = "Interface\\Buttons\\WHITE8X8" })
```

## Good

```lua
local f = CreateFrame("Frame", nil, UIParent, "BackdropTemplate")
f:SetSize(200, 100)
f:SetPoint("CENTER")
f:SetBackdrop({ bgFile = "Interface\\Buttons\\WHITE8X8" })
```
