# UX015: UICheckButtonTemplate on Forever

**Category:** ux

## Why

Machine-observed on Forever (Interface 16001): building check buttons from `UICheckButtonTemplate` took down the ForeverDungeons UI. Use `Settings.CreateCheckbox` on a `Settings.RegisterVerticalLayoutCategory` page, or build the check button yourself (`CreateFrame("CheckButton")` + `UI-CheckBox-Up` / `UI-CheckBox-Check` textures + a FontString label). Usage that only runs when `Settings` is missing (the standard UI kit's legacy fallback) is not reported. Runs only for addons whose TOC targets Forever.

## Bad

```lua
local panel = CreateFrame("Frame")
local check = CreateFrame("CheckButton", nil, panel, "UICheckButtonTemplate")
check:SetPoint("TOPLEFT", 16, -16)
```

## Good

```lua
local panel = CreateFrame("Frame")
local check = CreateFrame("CheckButton", nil, panel)
check:SetSize(24, 24)
check:SetPoint("TOPLEFT", 16, -16)
check:SetNormalTexture("Interface\\Buttons\\UI-CheckBox-Up")
check:SetPushedTexture("Interface\\Buttons\\UI-CheckBox-Down")
check:SetCheckedTexture("Interface\\Buttons\\UI-CheckBox-Check")

local function LegacyPanel()
    if Settings and Settings.RegisterVerticalLayoutCategory then
        return
    end
    return CreateFrame("CheckButton", nil, panel, "UICheckButtonTemplate")
end
LegacyPanel()
```
