# API004: Deprecated API

**Category:** api

## Why

Deprecated functions survive only as compatibility shims (`Blizzard_Deprecated*`) and are removed in a later patch. On Forever and Midnight the chat shims (`SendChatMessage`, `ChatFrame_OpenChat`, `ChatFrame_AddMessageEventFilter`, ...) are only defined while the `loadDeprecationFallbacks` CVar is on, so they can already be nil for some players. Move to the replacement now; keep the old name only as a guarded fallback (`local GetItemCount = C_Item and C_Item.GetItemCount or GetItemCount` is not reported).

## Bad

```lua
local count = GetItemCount(6948)
print(count)
```

## Good

```lua
local count = C_Item.GetItemCount(6948)
local Legacy = C_Item and C_Item.GetItemCount or GetItemCount
print(count, Legacy(6948))
```
