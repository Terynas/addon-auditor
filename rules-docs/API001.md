# API001: Call to a C_ namespace member that does not exist

**Category:** api

## Why

The namespace is real but the member is not part of it on any client the addon targets. This is the typical shape of an API invented by an AI assistant (`C_ChatInfo.SendMessage`, `C_PlayerInteractionManager.IsInteractingWith`) or a misspelling. The call throws `attempt to call a nil value`. Existence-checked calls (`if C_X and C_X.F then`, `C_X.F and C_X.F()`, `pcall`) are not reported. When the addon also targets a client without bundled API data (Classic), the finding is downgraded to info.

## Bad

```lua
local function Announce(text)
  C_ChatInfo.SendMessage({ message = text, chatType = "SAY" })
end
Announce("hello")
```

## Good

```lua
local function Announce(text)
  if C_ChatInfo and C_ChatInfo.SendMessage then
    C_ChatInfo.SendMessage({ message = text, chatType = "SAY" })
  else
    C_ChatInfo.SendChatMessage(text, "SAY")
  end
end
local CI = C_ChatInfo
local ok = CI.SendMessage and pcall(CI.SendMessage, {})
Announce(tostring(ok))
```
