# API006: Combat log (CLEU) used where addons cannot read it

**Category:** api

## Why

Forever does not deliver `COMBAT_LOG_EVENT_UNFILTERED` to addons, and on Midnight (12.0+) registering it errors; `CombatLogGetCurrentEventInfo` is unavailable to addon code on both. A CLEU-driven feature silently does nothing. Build on unit events, encounter events or the built-in damage meter. Code inside a client check (`if not isForever then`) is not reported.

## Bad

```lua
local f = CreateFrame("Frame")
f:RegisterEvent("COMBAT_LOG_EVENT_UNFILTERED")
f:SetScript("OnEvent", function()
  local _, sub = CombatLogGetCurrentEventInfo()
  print(sub)
end)
```

## Good

```lua
local f = CreateFrame("Frame")
f:SetScript("OnEvent", function(_, _, unit, _, spellID)
  print(unit, spellID)
end)
f:RegisterUnitEvent("UNIT_SPELLCAST_SUCCEEDED", "player")
```
