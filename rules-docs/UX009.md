# UX009: Options registered only with the removed InterfaceOptions API

**Category:** ux

## Why

`InterfaceOptions_AddCategory` was deprecated in 10.0 and removed from Mainline; an addon that only uses it has no options page there (or errors if it calls it unguarded). Register through `Settings` and keep the old call as a fallback for clients without it:

```lua
if Settings and Settings.RegisterCanvasLayoutCategory then
    local category = Settings.RegisterCanvasLayoutCategory(panel, panel.name)
    Settings.RegisterAddOnCategory(category)
else
    InterfaceOptions_AddCategory(panel)
end
```

## Bad

```lua
local panel = CreateFrame("Frame")
panel.name = "Fixture"
InterfaceOptions_AddCategory(panel)
```

## Good

```lua
local panel = CreateFrame("Frame")
panel.name = "Fixture"
if Settings and Settings.RegisterCanvasLayoutCategory then
    local category = Settings.RegisterCanvasLayoutCategory(panel, panel.name)
    Settings.RegisterAddOnCategory(category)
elseif InterfaceOptions_AddCategory then
    InterfaceOptions_AddCategory(panel)
end
```
