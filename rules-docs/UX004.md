# UX004: Movable frame not clamped to screen

**Category:** ux

## Why

A movable frame can be dragged partly or fully off-screen, or end up there after a resolution or UI scale change. Without `SetClampedToScreen(true)` the player may never get it back without deleting SavedVariables or layout cache.

## Bad

```lua
local f = CreateFrame("Frame", "FixtureMover", UIParent, "BackdropTemplate")
f:SetSize(200, 100)
f:SetPoint("CENTER")
f:SetMovable(true)
f:EnableMouse(true)
f:RegisterForDrag("LeftButton")
f:SetScript("OnDragStart", f.StartMoving)
f:SetScript("OnDragStop", f.StopMovingOrSizing)
```

## Good

```lua
local f = CreateFrame("Frame", "FixtureMover", UIParent, "BackdropTemplate")
f:SetSize(200, 100)
f:SetPoint("CENTER")
f:SetMovable(true)
f:SetClampedToScreen(true)
f:EnableMouse(true)
f:RegisterForDrag("LeftButton")
f:SetScript("OnDragStart", f.StartMoving)
f:SetScript("OnDragStop", f.StopMovingOrSizing)
```
