# PKG004: Release package is unusually large

**Category:** packaging

## Why

Counts every file the packager would ship (dot-paths and `.pkgmeta` ignores excluded) against `thresholds.package_size_mb_warn` (default 20 MB). Huge packages are almost always docs, videos or uncompressed source art shipping by accident.

## Bad

```yaml
Shipped files total 48.3 MB (docs/ and Art/*.psd not ignored)
```

## Good

```yaml
ignore:
  - docs
  - "*.psd"
```
