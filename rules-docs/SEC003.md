# SEC003: SetScript on a Blizzard frame

**Category:** security

## Why

`GameTooltip:SetScript("OnShow", fn)` removes the handler Blizzard installed (and whatever other addons hooked), so the default behaviour silently stops and the frame's script is tainted. `HookScript` chains your function after the existing one. Frames the addon created itself (`CreateFrame(..., "MyAddonFrame")`, XML `name=`) are not reported.

## Bad

```lua
GameTooltip:SetScript("OnShow", function(self)
  self:AddLine("MyAddon was here")
end)
```

## Good

```lua
GameTooltip:HookScript("OnShow", function(self)
  self:AddLine("MyAddon was here")
end)
local own = CreateFrame("Frame", "MyAddonFrame", UIParent)
own:SetScript("OnShow", function() end)
```
