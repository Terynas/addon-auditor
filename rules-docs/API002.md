# API002: Unknown C_ namespace

**Category:** api

## Why

No targeted client has this `C_*` namespace and the addon does not create it, so the first index throws `attempt to index a nil value` and the rest of the file stops loading. Guarded reads (`if C_X then`, `C_X and C_X.F`) are not reported.

## Bad

```lua
local function Shout(text)
  C_PartyChat.Send(text)
end
Shout("hi")
```

## Good

```lua
local function Shout(text)
  if C_PartyChat and C_PartyChat.Send then
    C_PartyChat.Send(text)
  else
    C_ChatInfo.SendChatMessage(text, "PARTY")
  end
end
Shout("hi")
```
