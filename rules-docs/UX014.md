# UX014: Hard-coded client font path

**Category:** ux

## Why

Client font files differ per locale: `FRIZQT__.TTF` has no Cyrillic or CJK glyphs, so Russian, Korean and Chinese players see empty boxes. Hard-coded paths also ignore UI font replacements. Blizzard font objects (`GameFontNormal`, `GameFontHighlightSmall`, ...) resolve to the right file for each locale. Custom fonts shipped inside the addon are not reported.

## Bad

```lua
local f = CreateFrame("Frame", nil, UIParent)
local label = f:CreateFontString(nil, "OVERLAY")
label:SetFont("Fonts\\FRIZQT__.TTF", 14, "OUTLINE")
```

## Good

```lua
local f = CreateFrame("Frame", nil, UIParent)
local label = f:CreateFontString(nil, "OVERLAY")
label:SetFontObject(GameFontNormal)
```
