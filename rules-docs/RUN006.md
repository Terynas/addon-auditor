# RUN006: Event storm

**Category:** runtime

## Why

Each event delivery calls into the addon. Registering broad events (BAG_UPDATE, UNIT_AURA for every unit, COMBAT_LOG) multiplies work in exactly the situations where the client is busiest.

## Bad

```lua
frame:RegisterEvent("UNIT_AURA")
frame:RegisterEvent("BAG_UPDATE")
```

## Good

```lua
frame:RegisterUnitEvent("UNIT_AURA", "player")
frame:RegisterEvent("BAG_UPDATE_DELAYED")
```
