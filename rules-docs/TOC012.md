# TOC012: No addon list icon or category

**Category:** toc

## Why

Since 11.1 the AddOns list and addon compartment show `## IconTexture` / `## IconAtlas` and group by `## Category`. Optional, but it makes the addon easy to find. Checked on the primary TOC only.

## Bad

```ini
## Title: Fixture
## Notes: auditor fixture
```

## Good

```ini
## Title: Fixture
## IconTexture: Interface\Icons\INV_Misc_QuestionMark
## Category: Utility
```
