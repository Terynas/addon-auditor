# UX016: Tooltip shown on enter but never hidden on leave

**Category:** ux

## Why

`GameTooltip` is shared by the whole UI. If an OnEnter handler claims it with `SetOwner` and nothing hides it on OnLeave, the tooltip stays on screen after the mouse moves away, covering the world until another frame takes it over.

## Bad

```lua
local btn = CreateFrame("Button", nil, UIParent, "UIPanelButtonTemplate")
btn:SetSize(120, 24)
btn:SetPoint("CENTER")
btn:SetScript("OnEnter", function(self)
    GameTooltip:SetOwner(self, "ANCHOR_RIGHT")
    GameTooltip:AddLine("Click to refresh")
    GameTooltip:Show()
end)
```

## Good

```lua
local btn = CreateFrame("Button", nil, UIParent, "UIPanelButtonTemplate")
btn:SetSize(120, 24)
btn:SetPoint("CENTER")
btn:SetScript("OnEnter", function(self)
    GameTooltip:SetOwner(self, "ANCHOR_RIGHT")
    GameTooltip:AddLine("Click to refresh")
    GameTooltip:Show()
end)
btn:SetScript("OnLeave", GameTooltip_Hide)
```
