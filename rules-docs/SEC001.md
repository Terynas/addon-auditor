# SEC001: Dynamic code execution (loadstring / RunScript)

**Category:** security

## Why

`loadstring`, `load` and `RunScript` compile a string and run it with the player's full UI privileges. If any part of that string comes from an addon message, chat, an EditBox or SavedVariables (which other tools and shared profiles can edit), whoever shapes the string runs arbitrary Lua: sending mail, deleting items, spamming chat. Parse data into plain values instead. Severity is `error` for non-constant input (confidence `high` when the source is visibly untrusted) and `info` for a constant string, which is merely pointless.

## Bad

```lua
local PREFIX = "MyAddon"
local f = CreateFrame("Frame")
f:RegisterEvent("CHAT_MSG_ADDON")
f:SetScript("OnEvent", function(self, event, prefix, message)
  if prefix ~= PREFIX then return end
  local fn = loadstring(message)
  if fn then fn() end
end)
```

## Good

```lua
local PREFIX = "MyAddon"
local handlers = {
  ping = function(arg) print("ping", arg) end,
}
local f = CreateFrame("Frame")
f:RegisterEvent("CHAT_MSG_ADDON")
f:SetScript("OnEvent", function(self, event, prefix, message)
  if prefix ~= PREFIX then return end
  local cmd, arg = message:match("^(%a+):(.*)$")
  local handler = cmd and handlers[cmd]
  if handler then handler(arg) end
end)
```
