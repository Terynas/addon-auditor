# TOC001: TOC file name does not match the addon folder

**Category:** toc

## Why

WoW looks for `<Folder>.toc`, or `<Folder>_<Suffix>.toc` where the suffix names a client (`Mainline`, `Standard`, `Forever`, `Vanilla`, `TBC`, `Wrath`, `Cata`, `Mists`, `Classic`, ...). Any other TOC is ignored. If no TOC matches, the addon is simply missing from the AddOns list -- the most common 'my addon does not show up' report. Names are case-sensitive on Linux/macOS.

## Bad

```text
MyAddon/
  MyAddOn.toc      <- case differs from the folder: never read
  core.lua
```

## Good

```text
MyAddon/
  MyAddon.toc
  MyAddon_Vanilla.toc  <- known client suffix
  core.lua
```
