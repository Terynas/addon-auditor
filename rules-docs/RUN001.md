# RUN001: Addon not loaded during the probe session

**Category:** runtime

## Why

Runtime rules compare this addon's samples against thresholds. If the probe never saw the addon (disabled, renamed folder, or the session ran before it loaded) every other RUNTIME rule is silently skipped, so the audit would look clean without any evidence.

## Bad

```lua
-- AuditorProbe.lua: the session lists other addons but not this one
```

## Good

```lua
-- AuditorProbe.lua: the session has mem/cpu samples for this addon
```
